# Online Retail Exploratory Data Analysis Dashboard

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the UCI Online Retail dataset using Python, Pandas, Matplotlib, Seaborn, and Streamlit.

## Features

- Data cleaning
- Missing-value analysis
- Duplicate removal
- Categorical variable analysis
- Statistical summaries
- Top 10 products analysis
- Country-wise analysis
- Monthly sales trend
- Streamlit dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook
